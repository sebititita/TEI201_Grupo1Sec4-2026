# Librerías

## Librerías Estándar (paquete ESP32)

1. **WiFi** — incluida en el paquete *esp32 by Espressif Systems*
   - Propósito: crear la red WiFi propia del ESP32 (modo punto de acceso)
2. **WebServer** — incluida en el paquete *esp32 by Espressif Systems*
   - Propósito: servir la página web y el estado en JSON

No se usan librerías personalizadas ni externas.

## Dependencias Completas

| Librería | Versión | Fuente | Obligatoria |
